IP 归属地批量查询

一次查几千条 IP 的国家、省份、城市和运营商。数据库下载到本地后离线比对，IP 不外发。

🔒 IP 不外发 📡 55 万条网段 ♾️ 不限条数 📊 可导出 Excel
查几个 IP 只读取数据库里用得上的那几十 KB，秒出结果；一次查 25 条以上才会下载完整数据库 （约 11 MB，下载完缓存在浏览器里，之后完全离线、秒开）。 这样做是为了不把你的 IP 列表发给任何第三方接口——那类接口不但限流严重，数据也等于交出去了。

说明
  • 只支持 IPv4。IPv6 的库有 37 MB，体积太大暂时没做，有需要跟我说。
  • 内网地址（10.x、192.168.x、127.x）会返回「保留地址」，这是正常的——它们本来就没有地理位置。
  • 不提供「查我自己的 IP」。浏览器拿不到自己的公网 IP，那必须请求第三方接口，和这个工具「不外发」的前提冲突。
  • 库里空缺的字段（比如境外 IP 常常没有城市）会留空，不编造。
「定位精度」这一列怎么看（重要）
  • IP 库是按网段登记的。一条记录如果只覆盖 256 个地址，说明登记得细； 如果一条记录覆盖二十万个地址却只写一个城市，那这个城市基本是凑出来的。
  • 本工具把命中的网段范围和地址数直接列出来，并按规模标注精度： 精确（≤1024）、较精确（≤16384）、一般（≤65536）、 粗略·存疑（超过 65536）。
  • 注意：库文件内部会把大网段在 /16 边界上切成几条，直接读会低估范围。 本工具已自动把切开的碎片合并还原，所以这里显示的是真实登记范围。
  • 真实例子：39.146.40.66 真实网段是 39.144.218.0 ~ 39.147.255.255， 整整 206,336 个移动地址全被登记成「重庆市」，标为粗略·存疑。 这种结果不能用来判断实际位置——换个 IP 库很可能给出完全不同的省份。
  • 移动、联通的 4G/5G 出口地址是全国混编的，这类 IP 的归属地天然不可靠。 固网宽带（电信/联通的家庭宽带）通常准确得多。
数据来源与准确度
  • 来自开源项目 lionsoul2014/ip2region，55 万条网段，数据更新于 2026-08-10。
  • 不同 IP 库对同一个地址给出不同答案是常态，尤其是移动网络和 CDN 节点。 凡是标注「粗略」「很粗略」的结果，都不能作为定位依据。
