怎么确认文件真的没上传？

每个在线工具都说自己安全。别信，包括我们的。自己验一遍，三十秒。

"文件不上传"这句话，网站说了不算——它可以一边显示"本地处理中"，一边在后台把你的文件发走， 你从界面上看不出任何区别。但浏览器看得见。每一个网络请求都逃不过开发者工具， 而这个工具是你的浏览器自带的，不受网站控制。

下面的方法对任何在线工具都适用，不只是我们的。学会了，以后你自己就能判断。

方法一：三十秒，看着它不发请求

  1. 随便打开一个工具页面，比如 Word 转 PDF。
  2. 按 F12 打开开发者工具（Mac 上是 ⌥+⌘+I）。 手机上没有这个功能，需要用电脑。
  3. 点顶部的 Network（网络）标签，然后按 Ctrl+R 刷新一下页面， 让它开始记录。
  4. 等页面加载完，点一下 Network 面板里的 清空 按钮，把已有记录清掉。 现在列表应该是空的。
  5. 选择你的文件，让工具处理，导出结果。
  6. 回头看 Network 面板——它应该还是空的。没有任何新请求， 意味着你的文件从头到尾没有离开过这台电脑。

如果换成一个会上传的网站，这一步你会看到一条 POST 请求， 体积和你的文件差不多大——那就是你的文件正在被发出去。

它保护不了什么

说实话比说漂亮话重要。"文件不上传"能挡住的是网站服务器拿到你的文件，挡不住这些：

  • 浏览器扩展：有页面读取权限的扩展能看到你在页面里放的任何东西。这是浏览器层面的问题，任何网站都一样。
  • 你自己的电脑：如果电脑本身中了木马，那什么网站都救不了你。
  • 公司或学校的网络审计：装了根证书的网络能解密所有流量。不过既然本来就没有流量，这条影响也有限。

另外坦白一点：本站的 IP 归属地查询 在查询少量 IP 时， 会按需向服务器请求 IP 数据库的对应片段——文件和查询内容本身不会发出去， 但服务器日志能据此推断你查的 IP 大致落在哪个网段。 介意的话，把整个网站下载到本地跑就完全没有这个问题。

一个明确的例外：USDT 交易记录查询

本页上面讲的所有验证方法和「不上传」承诺， 都不适用于 USDT 交易记录查询。

  • 查询链上数据必须把你输入的地址发送给 TronScan 的服务器，这一步没法在本地完成—— 区块链的完整数据有几百 GB，不可能下到浏览器里。
  • 所以用那个工具时，TronScan 会知道你查了哪个地址，也会记录你的 IP。 地址本身是链上公开信息，但「谁在查它」不是。
  • 如果这件事对你重要，别用那个页面——直接去 TronScan 官网查是一样的， 或者用你自己的节点。本站没有任何办法让这类查询变成本地的。

这个例外在首页单独分区、工具卡片上标了「需联网」角标、页面顶部也有红框说明。 把它和其他工具混在一起才是不诚实的做法。

最彻底的办法：把它下载下来离线用

本站全部代码是开源的、纯静态的，没有后端。你可以整个下载下来，断网使用：

  • 打开 github.com/plmxs-11/wenhuo，点 Code → Download ZIP
  • 解压后，用任意一个静态服务器打开，比如装了 Python 的话：
    python -m http.server 8123
  • 浏览器访问 http://localhost:8123/，然后把网线拔了，一样能用。

断网还能用，就是"不上传"最硬的证明——没有网络，它还能上传到哪儿去？
